# Reference-matched navigation
The supplied image has a continuous solid orange strip, a flat upper edge, rounded lower corners, and evenly spaced white icons. Flutter now implements that silhouette in the existing contrast-safe ocean/company branding color, with icon-only navigation, a subtle active treatment, semantic labels and long-press tooltips. The home header uses the same color and curvature; ordinary AppBars inherit it globally through the shared theme. Existing authorized destination count and routing remain unchanged, rather than hard-coding the four example icons. Form submit/action footers are not navigation and remain separate. No API or dependency changes. Physical visual comparison still requires device review.
