# Tide Flow / Editorial interface refresh

Dribbble research: Taskly (26209851), TaskCraft (27774774), mobile CRM directory patterns. Original implementation, not copied artwork. The existing ocean-blue wave background and company branding are preserved.

- Module pages have a branded contour hero and distinct record layouts: contact identity, date-focused installation/task cards, price/stock emphasis, product photos where authorized, notification feed, and directory details.
- Details use grouped sections rather than an undifferentiated key/value table. Reports and work notes use an actual-record timeline; no invented events or progress values.
- Forms have a contextual header, an organized entry surface, inline errors and a thumb-reachable submit dock. Original controllers, field definitions, validators, and submit callback are retained. Company logos and product images use existing restricted API paths.
- Account settings are grouped by purpose, auth fields use meaningful icons, and dialogs, sheets, loading and error states share the same style. No new dependencies.

This is an app-wide shared-component pass, not a claim of a handcrafted screen for every one of the 175 preview frames. Physical-device review and CI remain required.
