# Scoped GetX state management
Official get 4.7.3 stable pinned; no GetMaterialApp migration. Existing Navigator, API, server permissions and company scoping remain intact. Route-owned GetxController resources, explicit disposal, no global data cache. Obx on notification badges, tab body/navigation, dashboard data, company directory filter, operational data, local record filtering, sales period, and feature search. Refresh requests are not automatic write retries; only explicit read refresh. Native camera lifecycle and form controllers remain Flutter-managed. Further optimization requires profile-mode measurements, full build and device regression. Do not claim benchmark gains without traces.

Large operational lists use lazily constructed sliver rows rather than eagerly laying out every record in a column. Home refresh revisions preserve the widget identity and refresh dashboard data after return from operational routes; notification count changes update only consumers. Existing form and scanner lifecycles are deliberately retained.
