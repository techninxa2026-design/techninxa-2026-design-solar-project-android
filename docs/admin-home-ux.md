# SuperAdmin landing page and accessibility presentation
Source baseline: MVC main 08e53d4fc91a87abe4a12bd07a6d71bc8eb8f319. Dedicated platform console replaces shared employee landing page at root SuperAdmin. Uses GET /companies items and memberCounts, not invented metrics. Network total, active/inactive proportion, DA and installer totals, direct register/open workspace actions, notifications and filterable company preview with actual logo. Full company directory remains available. Find a feature launches a focused searchable route with grouped authorized results, clear control and feature descriptions; company-level operations still require a selected workspace. All 19 accessibility names/descriptions/groups are sourced from MVC OpsPowers, OpsAccessibilityCatalog and OpsPowerPages. The checkbox selection only includes server-returned delegable permissions and submits unchanged keys. No API, database or authorization change. Automated tests use fixtures; actual device look and touch behavior require on-device review.
