# IDCOLDA app branding
The supplied solar-brand artwork is the canonical logo: blue solar panel, amber sun, and connected cyan nodes. It is rasterized to a transparent 192 × 192 WebP, with no SVG asset or SVG rendering dependency at runtime. The original illustration's shape and colors are retained (WebP compression may slightly change edge pixels). Android launcher uses the same image over the existing blue background; Android 8+ uses the existing adaptive icon safe inset. Flutter uses it in the platform BrandMark and splash with a separate IDCOLDA wordmark. Company-specific logos remain unchanged.
The existing signed Android release GitHub Actions workflow is preserved. Asset changes trigger the workflow. Signed builds require the permanent signing secrets; publication remains controlled by the MVC SuperAdmin. Check physical launcher masks and startup appearance before publishing.
