# IDCOLDA app icon
Approved solar-panel, sun and connected-network design. The original artwork was resized to 192 × 192 WebP for Android and Flutter, with the white outer corners filled in blue. Both assets share the identical Git blob. The launcher uses a legacy bitmap below Android 8 and an adaptive icon with inset artwork on newer devices. The Flutter startup screen and platform BrandMark use the same local artwork; company-specific logos remain unchanged. No dependencies or permissions added.
