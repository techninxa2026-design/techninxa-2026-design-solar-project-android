# Mobile hierarchy and record action UX
The prior editor squeezed instructions, search, roster and a fixed-size graph into the same mobile viewport. The replacement defaults to a responsive reporting directory, with explicit parent names, employee and department information, collapsed branches, counts and search. An optional visual editor keeps drag/drop and the six existing MVC operations. Fit-to-view and zoom around viewport center improve navigation. Guided assignment/move choices reuse the same command validator and confirmation as dragging. Shared action docks show a named button rather than an ellipsis, with the single safe action directly accessible and destructive actions kept in the sheet. Subrecord action footers are embedded in their record card; duplicate company header actions removed. No server authorization, command schema or database changes. Source review and fixture tests, not a physical-device walkthrough.
